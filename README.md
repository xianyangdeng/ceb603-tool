# CEB603 清单报文生成工具（9610 · 客户校验版）

读取精简 Excel 模板 → 客户登录校验 → 生成标准 CEB603 XML 报文。

## 功能特性

- **客户校验登录**：打开网页弹出登录层，需输入 `clients.csv` 中的海关编码，匹配成功才可使用
- **agentCode 一致性校验**：生成报文时校验模板「清单表头」的 `agentCode` 是否与登录海关编码一致，不一致则拒绝生成
- 每批 ≤99 单自动拆分报文
- itemNo 禁止含俄语 / 禁止超 20 字符
- 必填项校验（gmodel、barCode、currency 除外）
- 空值字段自动删除
- 多份报文自动打包为 ZIP 下载

## 使用方式

### 方式一：本地启动（推荐）

因为浏览器 `file://` 协议下无法读取本地 CSV，需通过 HTTP 服务打开：

**Windows**：双击 `serve.bat`
**Mac / Linux**：终端执行 `bash serve.sh`

浏览器自动打开工具页面。

### 方式二：部署到静态服务器 / GitHub Pages

将本目录所有文件上传到任意静态服务器或 GitHub Pages 即可。

## 客户列表维护

编辑 `clients.csv`，每行一个客户：

```csv
# 第一列=海关编码，第二列=单位名称
1105910159,深圳市示例科技有限公司
4420960ABC,中山市测试贸易有限公司
```

- 支持 UTF-8 带 BOM / 不带 BOM
- 支持逗号分隔或制表符（Tab）分隔
- 海关编码自动处理：去空白、全角数字转半角、去尾零（如 `1105910159.00` → `1105910159`）
- 首列空行或 `#` 开头视为注释，会被忽略

## 校验流程

```
打开网页
  → 弹出登录层（主界面隐藏）
  → 输入海关编码 → 与 clients.csv 比对
  → 匹配失败：提示"不在客户列表中"，无法使用
  → 匹配成功：显示主界面，记录当前客户

选择 Excel 模板
  → 点击"生成清单报文"
  → 校验① agentCode 是否与登录海关编码一致（逐条核对清单表头）
  → 校验② 必填项是否填写
  → 校验③ itemNo 是否含俄语 / 超 20 字符
  → 任一不通过：提示问题订单，不生成报文
  → 全部通过：生成 XML，按 ≤99 单拆分
```
